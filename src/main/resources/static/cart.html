🛒 Cart Order Service

Cart Management Dashboard

Display products first, select items, add to cart, view orders and remove products.

🔑

Service Credentials

REQUIRED

Place Order, All Orders, Ship Order, Deliver Order and Delete Product require the same X-Service-Key value as this service's .env. Place Order also requires the buyer's own PhonepayService session token, sent exactly as PhonepayService expects it (e.g. Bearer <token>) - that is who gets charged. Both are remembered in this browser only.
